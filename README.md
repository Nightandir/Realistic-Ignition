# Realistic Ignition

Minecraft 1.21.11 + Fabric add-on.

## Scope
A standalone gameplay-mechanics add-on. It should make vanilla furnaces, blast furnaces and smokers require deliberate ignition while preserving normal flint-and-steel use on blocks and portals. This project adds no items, blocks or recipes of its own.

## Integration plan
The optional Primitive Ignition: Crafting add-on will provide the primitive ignition item. Realistic Ignition should work without that add-on using vanilla flint and steel, and recognize the primitive item when it is installed. Cross-mod integration must be verified before release.

## Build status
Initial project scaffold only; ignition hooks are not yet ported/verified for 1.21.11 and the project has not been compiled or tested in Minecraft.
